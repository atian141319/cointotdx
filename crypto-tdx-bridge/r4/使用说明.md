# 币安现货 → 通达信本地同步（R4显示试验版）

## 启动

双击 `release/CryptoTdxSync.exe`，无需安装Python，无网站。当前机器提供的 `settings.json` 已指向项目内隔离客户端和独立精确数据库；保留原安装。通达信代码为 **397901 / BTCUSDT / sz外部品种**。

1. 在“通达信与数据”检查安装目录、tdxw.exe、实际vipdoc目录、独立精确数据目录。
2. 点击“检查配置”，确认注册身份；点击“开始同步”。
3. 点击“启动通达信”，进入游客行情，输入397901，打开图表。工具栏选择1、5、15、30、60分钟；日、周、月按客户端周期切换。
4. “状态与日志”显示连接、数据库、文件更新时间、补缺及错误。运行中保存配置会安全停止旧连接、重连补缺。点击“停止同步”取消待重载并等待有限请求退出。

## 连接及恢复

本机实测 `wss://data-stream.binance.vision` 可用；另外两个官方端点本次DNS失败。点击“真实连接测试”复测实际机器。代理仅用于应用WebSocket，不改系统代理；REST保持直连。网络中断、休眠后自动重连并补历史；关机期间不运行，重新开始同步补缺。

启动和重连先持久接收事件，再REST补齐，按同根K线累计快照更新。429/418复用跨进程冷却；403/418/451和解析异常明确停止本轮REST，实时连接状态单独报告。记录UTC开盘时间，电脑时区不改变边界。当前K线不冒充已收盘。

## 币种和注册

添加、编辑、删除、启停币种后保存配置；删除/停用保留历史。BTC固定397901，当前支持已验证的sz外部397xxx关联。新币先“校验交易对”，配置无冲突代码；同步精确数据后“准备外部注册”导出日线TXT。

沿用已成功的客户端外部品种导入入口：日期/开/高/低/收/基础币数量/USDT成交额，Tab分隔，无表头、忽略0行、YYYY-MM-DD；填代码后3位和简称。此注册步骤仍需人工操作。检查配置确认lcext.lei实际身份后才写入该币种缓存，未注册不影响其他币种。不能用搜索得到名称代替注册成功。

## 显示精度与保护

**这是有损显示试验，不能作为精确量价验收。** 精确字符串保存在独立SQLite和原始响应中。分钟价格/成交额float32、基础币量截断为整数（小于1可显示0）；日线价格×1000表示。每次写入逐字段记录原值、表示值、误差，尾部0仅试验假设，语义未确认。周/月图由日线归并，长周期完整性与源数据需单独复核。

LC1/LC5/DAY只写本工具确认身份的文件。首次备份及哈希在精确数据目录 `display/backup`；批次、误差及回滚日志在 `display/batches`。占用失败保留待更新重试；多文件不具备客户端层面的同时读取事务，批次标识用于复核，进程中断后先恢复未完成批次。不要同时运行其他程序写这些文件。

一键恢复：停止同步，正常关闭隔离通达信，点击“恢复管理文件”。恢复首次写入备份，精确历史保留，不强杀客户端、不修改程序或注册配置。复验图表可点击“记录当前图表证据”；“重绘”不等于缓存重读。已在本机运行客户端观察自动变化，不自动反复重启。

## 源码构建

本次构建环境 Windows 11 x64、Python 3.14.7；依赖锁定在requirements文件。项目根运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File r4/build.ps1
python -m unittest discover -s r4 -p test_r4.py -v
```

构建需联网安装公开依赖；运行程序只访问币安公开现货。EXE未签名，不含账户或交易功能。整体仍为PARTIAL，未登记完整产品PASS。
