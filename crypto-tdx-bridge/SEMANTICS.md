# 时间及量价口径（第一版）

原始交易所/市场固定为 binance/spot。八个周期为 1m、5m、15m、30m、1h、1d、1w、1M。API 请求显式使用 timeZone=0；UTC 保存，不随 Windows 时区变化。

分钟线按 24 小时连续时间分桶，日线从 UTC 00:00 开始；周线为 UTC 周一开始；月线为自然月首日开始，不按固定 30 天计算。历史起点向下对齐各周期开盘边界，因此较大周期可能包含起点之前的交易。结束参数选择开盘时间早于该结束点的交易所原生 K 线，不裁切原生 K 线的 OHLCV。原生完整日/月线和十分钟样本的本地聚合不能互相冒充。

所有价格、币数量、计价币成交额保留 API 十进制字符串。SQLite 以 JSON 文本保存整根原始 K 线，唯一键为交易所、市场、交易对、周期、开盘时间。同一值重复抓取不增加修订；值变化记录旧值、新值和各自原始响应 ID。

价格单位为每单位基础币的计价币数量；BTCUSDT 的量为 BTC、金额为 USDT。没有“手”、人民币转换或价格缩放。审计 CSV 原字符串精确输出，不引入二进制浮点量价误差；没有固定整数价格缩放及其溢出范围。Decimal 聚合使用 80 位有效数字，开启 Inexact 异常，超出精确表示范围时拒绝计算；聚合辅助函数不接入当前发布路径，不能静默舍入。

收盘判定使用 K 线请求之前取得的币安 serverTime，且 closeTime < serverTime。未收盘和已收盘通过 final 标记区分，审计 CSV 只输出 final=1。缺失记录保留为缺口，不填充。聚合输入缺分钟、重复分钟或尚未结束时标记 complete=false，不输出为完整聚合历史。当前发布直接使用八个原生周期，避免多年分钟数据下载。

审计输出标签为 UTC 开盘时间，close_utc 是交易所包含在周期内的最后一毫秒。通达信显示时差、时间标签及格式尚未冻结；不对未验证的目标格式静默转换。外部品种设置的 0–3 位小数精度是否改变存储、量额是否溢出仍为 GPT 复核阻断项。

批次发布使用不可变 batch 目录、文件 SHA-256、manifest 和原子替换 CURRENT.json 指针。消费者先读取一次指针，并只读取该批次清单的文件。失败批次可能残留，但不会成为 CURRENT；保留前一批有效结果。这个协议尚未接入通达信。
